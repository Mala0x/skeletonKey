# skeletonKey

SkeletonKey is a big project that aims to make a highly modular and customizable protocol and device sniffer. This is not the only thing it aims to be. This project mostly aims to be a open source completely custom device for nerds to use and expand upon mostly inspired by the flipper zero and pwnagotchi.

This project is still in it's very early stages so a clear image of what this project is going to be and how it is structured is still very unknown. But I know that this project will be a ton of fun to work on and a huge learning opportunity in so many places. So be patient and watch how this project grows into something cooler every day.

I will try and limit my AI usage to the complete minimum, I do use it to brainstorm sometimes or when I cannot find the answer to a burning question using an "old school" $SEARCH_ENGINE. But I will not allow any AI generated code to enter the codebase. I actually want to learn from this project and therefore I think AI will not fit into that mental picture of what this project aims to bring to me personally.
